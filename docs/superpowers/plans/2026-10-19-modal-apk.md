# Modal APK Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the APK's Termux dependency with official Claude Code on Modal.
**Architecture:** A one-file Modal service provides authenticated script generation and a restricted browser login terminal. A deep link pairs the Android app, which keeps its existing local video renderer.
**Tech Stack:** Python, Modal, FastAPI, Kotlin Compose, Android Keystore, GitHub Actions.
**Spec:** docs/superpowers/specs/2026-10-19-modal-apk.md

## Global Constraints
- Official unmodified Claude CLI; no API key or custom OAuth.
- HTTPS Modal endpoints only; explicitly confirm connection; encrypted local credential storage.
- Bound cloud time and concurrency; preserve local rendering and honest automation limits.

## Review Focus
- Malicious pairing URLs must not receive credentials.
- Unauthenticated HTTP/WebSocket clients must not start Claude.
- CLI timeout/disconnect must release processes and save completed authentication.
- Interrupted pairing must leave previous configuration intact.
- A missing cloud deployment must not appear connected or disable manual video creation.
