# Modal connection for the existing APK

Use the existing Kotlin APK and its working Android video renderer. Replace Termux's Ask Claude path with a private HTTPS Modal service running the unmodified official Claude Code CLI. Keep manual scripts and YouTube sharing usable without a server. No Anthropic API key, custom Claude OAuth or credential extraction.

One-time setup runs in the signed-in Modal Playground: deploy the service, print a private setup link, then tap Connect APK. The link contains a generated app access credential; Android stores it encrypted with Android Keystore. Users never type an endpoint or token. Only HTTPS Modal endpoints are accepted. Pairing requires explicit confirmation inside the APK.

The Accounts screen embeds a narrowly scoped connection page. Official Claude authorization pages open in the external browser; an official one-time login code, if requested, goes to the official CLI through a restricted PTY. Persist the CLI home in a private Modal Volume; serialize login/generation and commit on completion. Protect HTTP calls with constant-time bearer checks and WebSockets with first-message authentication plus same-origin checks. Never expose a shell.

Scale to zero, maximum one cloud container, 4 GB requested RAM. Enforce login and generation timeouts. The $1 trial may restrict deployment; no payment or budget change is authorized by this implementation. Actual subscription login and device behavior require the user's interactive test.

APK remains a hybrid: video rendering and approximate WorkManager schedules run on Android; this does not implement always-on cloud rendering or unattended YouTube uploads. Explain that limit in the UI and documentation.
